## 2. Navigating the CMS Modules

### 📊 Dashboard (`/admin/dashboard`)
Displays real-time system metrics, catalog counts, unread contact inbox messages, search engine indexing health, and quick actions.

### 📄 Pages & Sections Manager (`/admin/pages`)
Control route visibility (`Published` / `Hidden`) and edit the Hero section headline, titles, and narrative text.

### 🚀 Project Catalog Manager (`/admin/projects`)
- **Add New Project**: Fill in title, slug, category (`Python / Backend`, `Cloud`, `DevOps`, `AI / ML`), description, problem, solution, technologies list, and GitHub repository URL.
- **Edit & Delete**: Modify active projects or archive/delete entries.

### ⚡ Skills Matrix Manager (`/admin/skills`)
Manage technology items across 3 core competency tiers:
1. `CORE` (Production Ready)
2. `CURRENTLY BUILDING` (Active Learning Track)
3. `APPLIED` (Project Demonstrated)

### 🧪 Engineering Lab Manager (`/admin/lab`)
Control the 7-node visual roadmap track (`PYTHON` → `LINUX` → `DOCKER` → `CI/CD` → `AWS` → `TERRAFORM` → `KUBERNETES`). Edit learning objectives, node status, and system architecture blueprints.

### 📅 Experience Manager (`/admin/experience`)
Manage career timeline entries, degree milestones, verification indicators, and key responsibilities.

### 📑 Research Manager (`/admin/research`)
Update publication status, journal metadata, DOI, and explainability methodology for **AI-HealthGuard**.

### ✍️ Writing Manager (`/admin/writing`)
Manage technical article dispatches and Medium publication links.

### 🖼️ Media Library (`/admin/media`)
Inspect and manage registered public media assets (PDFs, SVGs, MP4 videos, images).

### 🧭 Navigation Manager (`/admin/navigation`)
Reorder header navigation links and toggle visibility.

### 🔍 SEO Settings (`/admin/seo`)
Control site title, meta description, keywords, OpenGraph tags, and search engine robots indexing toggle (`INDEX` / `NOINDEX`).

### 🎨 Design & Motion Manager (`/admin/design`)
Control theme tokens, functional morphing interaction system (`ON` / `OFF`), page transitions, and motion intensity (`Low`, `Medium`, `High`).

### 📬 Contact & Inbox Manager (`/admin/contact`)
Set display email, toggle interactive terminal contact form, client-side spam protection, and view received messages in the **Contact Inbox**.

### 💼 Resume Assets Manager (`/admin/resume`)
Select and update the active public ATS resume PDF asset (`/resume/Tarun_Kumar_Resume_ATS_OnePage.pdf`).

### ⚙️ System Settings (`/admin/settings`)
Configure site canonical URL, default publishing state, and review database migration options.
